# Used-Car Pricing & Procurement Analytics

## 1. Business Context
Alliance Automotive Group (AAG) evaluates used-car listings to support procurement decisions for the NextDrive platform. This project analyses market supply, pricing behaviour, inventory liquidity and procurement opportunities using SQL and Power BI.

## 2. Business Questions
- What does the current used-car market look like?
- Which vehicle attributes influence listed prices?
- Which vehicles are slow-moving inventory?
- Which listings are potential procurement opportunities?

## 3. How the Questions Were Answered
**SQL Server**
- Data profiling
- Data cleaning
- Business rule validation
- Procurement feature engineering

**Power BI**
- Star schema
- DAX measures
- Interactive dashboards
- Business insights

## 4. Tools
SQL Server • Power BI • DAX • Star Schema • Data Profiling • Data Visualisation
